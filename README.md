# 📚 Học .NET

Repository lưu trữ các bài tập và dự án học tập .NET Framework.

## 📖 Nội dung

- Bài tập hàng tuần về .NET
- Ứng dụng WPF với kiến trúc MVVM
- Entity Framework ORM
- Bài tập lớn

## 🛠️ Công nghệ sử dụng

- **.NET Framework**
- **C#**
- **WPF** (Windows Presentation Foundation)
- **Entity Framework 6**
- **MVVM Pattern**

## 🚀 Cách sử dụng

1. Clone repository
2. Mở solution file (.sln) bằng Visual Studio
3. Build và chạy project

## 📝 Ghi chú

Repository được tạo nhằm mục đích học tập .NET và xây dựng các ứng dụng desktop với WPF.
